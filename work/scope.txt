# Mỗi dòng một pattern:
#
#   order/         cho phép mọi thứ dưới order/

#
# Lưu ý: * khớp cả dấu / (order/* cũng khớp order/sub/a.go).

# Xoá hết pattern sau khi task xong.

# phiên đang chạy — không bao giờ đi vào git. Gate 3 (scripts/check-scope.sh) và

# còn pattern mà cây làm việc vẫn giữ ⇒ Gate 3 đỏ; khối commit đưa file này vào
# mà nội dung còn pattern ⇒ Gate 7b kêu. THÊM khối của bạn ở dưới khi bắt một
# task, và GỠ nó trước khi giao khối commit cuối cùng của task đó (§7.3) — đừng
